# Support policy

EnviousWispr for Windows is currently limited to founder and private-beta engineering use. There is no
publicly supported binary, hardware minimum, response-time SLA, or stable release channel yet.

Use the repository's private-beta bug/crash or product-feedback issue form for authorized prerelease builds.
Use GitHub private vulnerability reporting for security problems. Before filing a normal issue, record the
release channel and version, Windows edition/build, coarse hardware class, failed product stage, frequency,
and sanitized steps. Attach only the privacy-safe diagnostics export produced by EnviousWispr.

Never submit transcript or polished text, audio, clipboard or surrounding text, credentials, API keys,
account names, private file paths, target-window titles, stable device identifiers, raw logs, or crash dumps.
Replace private application, file, and account names with generic labels.

The current engineering target is Windows 11 x64. ARM64, public hardware requirements, Store/MSIX support,
and public customer-support commitments are later release decisions. Unsigned development packages are not
supported and must not be redistributed. Installer, update, rollback, data-preservation, compatibility, or
performance reports should identify the exact signed candidate and link the corresponding release issue.
