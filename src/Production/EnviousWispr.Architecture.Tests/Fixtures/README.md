# Deterministic parity fixtures

These fixtures are derived from the public EnviousWispr macOS repository pinned at commit
`f9b70283326254aad6974cceb33ca41316e493ec`. They are committed here so the Windows repository can
validate deterministic behavior without cloning another repository or depending on a personal machine.

| File | Purpose | Rows | SHA-256 |
|---|---|---:|---|
| `deterministic-parity.json` | Curated end-to-end Windows pipeline cases, including documented intentional differences | 37 | verified by source control |
| `macos-itn-parity.jsonl` | Privacy-filtered exact-output oracle generated by the pinned macOS ITN implementation | 2,084 | `97DF231DDC13FA508B38A5FE4F0D8F8DA8FC027E383CF9A6EEC384DF76ABF818` |
| `macos-itn-parity-holdout.jsonl` | Independently selected, privacy-filtered exact-output holdout from the same pinned oracle | 3,756 | `A176F184A9170857246E03EB11020D93A4729F62D06491A534C11A00114D7C27` |

The JSONL rows cover currency, dates, email, negative numbers, general numeric forms, phone numbers,
spoken punctuation, times, and URLs. Tests compare every expected byte; they do not merely check that an
output is non-empty. Public real-dictation slices and founder-like email examples were deliberately
removed before commit because this repository does not accept user content, even when an upstream source
is public.

The bundled emoji dictionary under `EnviousWispr.PostProcessing/Resources` is also copied verbatim from
the pinned public snapshot. Its SHA-256 is
`6E655D6332645E9BC414A17E0605BF11B533D0AA0CA5C14825A6BB786ACA3BD4`.

The upstream and Windows repositories are the same GPL-licensed product lineage. No model weights,
private user content, machine paths, or secrets are contained in these fixtures.
