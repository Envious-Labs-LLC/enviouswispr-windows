# Codex adapter for EnviousWispr Windows Edition

Before meaningful work, read the root `CLAUDE.md` in full. Then read
`.claude/knowledge/INDEX.md` and every file it routes for the current task.

The repository must stand on its own. Personal machine instructions can add helpful context, but they
must not be required to understand, build, validate, or hand off this project.

## Working agreement

- Saurabh is the founder, product owner, and final decision-maker.
- Preserve the founder-tested proof while the production architecture is built beside it.
- Reuse verified lessons from the macOS product. Do not copy Apple-specific machinery or stale history.
- Use simple English in founder updates. Separate measured facts from source evidence and assumptions.
- Use GitHub Issues for persistent work. Do not create markdown task trackers.
- Work on a branch, validate, commit, push, and open or update a pull request.
- Never merge a pull request unless Saurabh explicitly asks for that exact merge.
- Never commit secrets, model weights, private machine paths, or user content.
- A compile or unit test is not runtime proof. Complete the relevant native Windows user path or state
  exactly what remains unobserved.

The current product contracts live under `.claude/knowledge/`. Existing measurements and experiments
remain under `notes/` as evidence, not as the forward-looking source of truth.
